## Your task

Design the **Ladder component family**. Not a full 16-team assembled table with real data.

---

## Do NOT deliver

- Complete ladder graphic with real teams and points
- Results match modules or player stat rows
- Multi-grade pagination layouts

---

## DO deliver

- [ ] Ladder Metadata (+ long grade name)
- [ ] Column Header (+ minimal P/W/L/BYE/PTS and full column set variant)
- [ ] Ladder Row — default (+ missing logo, long team name)
- [ ] Rank — emphasis for position 1 (and optional last place — note if used)
- [ ] Team Identity (row) — reuse Results crest well if applicable
- [ ] Stat Cells — PTS dominant; Q/N/R tertiary
- [ ] Highlight State — bias row treatment (subtle)
- [ ] Compact Ladder Row — for 14–16 team density
- [ ] Ladder Table **wireframe** — metadata + header + 3 placeholder rows

---

## Hierarchy

1. PTS + Rank  
2. Team name  
3. Other stat columns  
4. Quotient / N/R (tertiary)

---

## Visual language

Extend Stadium Signal from Results. Table chrome may differ from match cards but primitives (crest well, stat cells, footer) should feel cohesive.
