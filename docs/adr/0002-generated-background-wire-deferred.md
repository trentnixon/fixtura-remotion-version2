# Generated is the product category; wire values stay legacy until a versioned rollout

Generated backgrounds is the single operator-facing category and internal catalogue for Graphics, Pattern, Particle, and Noise presets. Phase 1 keeps Graphics, Pattern, Particle, and Noise as external `useBackground` values so composition IDs, caches, callers, and existing payloads stay stable. Compatibility adapters normalize those legacy wire values into the Generated catalogue. Introducing `useBackground: "Generated"` requires a separate versioned rollout that accounts for composition IDs, caches, callers, discovery clients, and CMS data. Shipping the cleaner payload value earlier would force coordinated ID and cache invalidation without a product need in Phase 1.
