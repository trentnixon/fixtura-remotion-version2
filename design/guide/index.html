    Design prototype guide

    Static 1080×1350 HTML for layout approval before Remotion implementation. Run npm run design from the repository root, then open http://localhost:3456/design/.

    Frame contract

    Every exported asset is a 1080 × 1350 portrait frame:

    • Asset header — organisation / competition identity
    • Composition content area — sport-specific modules
    • Asset footer — organisation + sponsor lockups

    See component anatomy overview (open in editor) for shared primitives and block names.

    Tailwind vocabulary

    • font-teko — display / scores (Broadcast Pro)
    • font-rajdhani — labels / body (Broadcast Pro)
    • Utility-first layout: flex, gap-*, text-*

    Design pages use CDN Tailwind for speed. Remotion uses the package tailwind preset and theme componentStyles after handoff. Verify typography in Remotion Studio before sign-off.

    Fixtures & hydration

    Key copy is loaded from the same JSON as Remotion Studio (testData/samples/). Paths are declared in design/_shared/routes.json; DOM mapping lives in design/_shared/hydration/{variant}/{sport}/{asset}.bind.json.

    Add a new asset

    1. Create design/variants/{variant}/{sport}/{asset}.html
    2. Add bind map under design/_shared/hydration/...
    3. Register in design/_shared/routes.json
    4. Add row to design/.docs/asset-index.md
    5. Add handoff comment block at top of HTML

    Handoff to Remotion

    When a design prototype is approved:

    Move design/variants/{variant}/{sport}/{asset}.html to Remotion. Registry: {RegistryId}. Composition: {composition}. Update theme composition surface and display component. Map HTML classes to theme keys per variant readMe.

    Authoritative theme mapping: Broadcast Pro variant readMe

    Stitch briefs (design tool prompts): stitch-briefs index
